## Engine selection and fallback (who decides)

1. **Config** `PipelineConfig` (apps/web/src/lib/live/pipelineConfig.ts:36-63): `stt.{family,variant,whisperSize}`, `tts.{family,variant,voice,speed}`, `language`, `allowRestricted`. Defaults: Whisper base + Kokoro `af_heart`, English (:49-63). Saved in `ui.json` voice prefs; read fresh per TTS/turn call. Flow/Dictate overlay their own picks via `withSurfaceVoice` (:547-559).
2. **Catalog mirror**: `STT_FAMILIES` / `TTS_FAMILIES` (:211-294) mirror the agent's `NATIVE_FAMILIES`, cut to the 10 curated languages; `web-catalog.test.ts` keeps them in step. `isNativeVariant` (:307) = family.native ⇒ runs on the agent, nothing loads in the browser.
3. **Restricted licenses** (`restricted`, `permitted`, `chooseVariant` :309-374): Pocket, clone, and restricted Piper voices are refused unless `allowRestricted`; `engineMenu.licenseTag` (engineMenu.ts:26-40) classifies the agent's license strings (NC/research/AGPL/SA → restricted; MIT/Apache/BSD/CC0/CC BY/OpenMDW/OpenRAIL-M/NVIDIA OML → open).
4. **Language switch**: `pickCompatible(cfg, lang, catalog)` (:396-419) swaps any engine that cannot speak the new language: same family's language default → other variants → (from browser) browser then `LANGUAGE_DEFAULTS[lang]`, (from native) recommended then browser → any native, preferring installed ones, flagging `needsDownload`. `LANGUAGE_DEFAULTS` (:344-355): en parakeet-0.6b-v2 + kokoro; es/fr/it/pt parakeet-v3 + kokoro-multi; de parakeet-v3 + piper thorsten; hi/zh nemotron-3.5 + kokoro-multi; ja/ko nemotron-3.5 + supertonic. `browserTtsFallback(lang)` (:359) = kokoro (en) else supertonic (es fr de it pt hi ja ko) else null (zh has no browser voice).
5. **Runtime routing** (models.ts): `stt()` (:589-610) tries the native engine, on failure `nativeSttFailed` (:407-421) marks a *lasting* failure (HTTP 400/404/409/502, nativeFailure.ts) and falls back to Whisper for the call (asking to download the checkpoint if missing); one-offs fall back for that utterance only. `ttsStream()` (:694-757): native/agent-copy → on lasting failure or 2 hung sentences `ttsFallback` → `browserTtsFallback(lang)` for the call; one-off → retry once, then the sentence is unspoken (never a voice change mid-reply). Clone → `cloneTts` (:618-642) → browser voice on lasting failure. Agent copy of Supertonic (`agentCopy`, :312-330) is used whenever `GET /api/voice/engines` lists `supertonic-3` as `installed && runnable`, else the browser's.
6. **Where a native engine runs** (`accel.ts`): every engine starts on CPU with `threadsFor(device)` threads (half the P-cores on Apple Silicon else a third of physical cores, cap 4; device.ts:187-190). After first use and 30 s voice idle, `benchEngine` (native.ts:173-190) forks `native-worker.ts` as a child per provider and measures load, warm, median first-output ms and RTF on a fixed input (`BENCH_TEXT`, 5 s synthetic audio; accel.ts:177-186); `chooseProvider` picks an accelerator only if RTF ≤ 0.8 × CPU (`MIN_GAIN` 0.2, accel.ts:32-46). Results keyed by device fingerprint + files in `<home>/data/voice-accel.json`; a provider failing in a real call is retired (`markFailed`); users can override per engine (`PUT /voice/perf/engines/:id`). Providers: sherpa builds carry CoreML on darwin only; onnxruntime-node lists cpu/webgpu/coreml on macOS arm64, DirectML on Windows, CUDA separately on Linux (device.ts:112-177).
7. **Worker limits**: one worker thread per kind (asr, tts, speaker, addressee; native.ts:25-49), at most 2 loaded models per worker (LRU), idle unload after 5 min, one job at a time per handle (native-worker.ts:75-78,201-261).

## Downloads and caching

- **Browser weights** (Whisper, Kokoro, Supertonic, Smart-Turn): fetched from `https://huggingface.co/<repo>/resolve/main/<path>` (weights.ts:17) only after consent (`agreeTo`; the worker refuses any URL not in `allow`, models.worker.ts:8-9). Sizes shown beforehand from the hub tree API (`downloadPlan`, weights.ts:79-108; 8 s timeout). Cached in Cache API: transformers.js `transformers-cache`, hand-fetched files in `openlive-models-v1` (turn.worker.ts:28-36, supertonic.ts:14-50). `localStorage["openlive-models-ready-v1"]` records loaded `tier:stt:tts` tags so a refresh does not re-ask (models.ts:75-96). `removeModel` clears matching URLs (models.ts:103-117). Mid-call engine/language switches raise a `DownloadAsk` instead of fetching silently (models.ts:345-392).
- **Agent engines**: `POST /api/voice/engines/:id/download` streams JSON-lines `{loaded,total}`/`{done}`/`{error}` (routes.ts:231-262); `downloadEngine` (native-models.ts:404-434) streams `.tar.bz2` (GitHub `k2-fsa/sherpa-onnx/releases/download/{asr-models,tts-models,vocoder-models,speaker-recongition-models}`), a bare `.onnx`, or per-file from a Hugging Face revision URL into `<home>/data/models/<id>.part`, verifies every listed file, then renames into place (no half installs). `DELETE /api/voice/engines/:id` cancels or removes. Legacy ids are renamed once (:330-336). `engineInstalled` = all `files` present (:341).
- **ZipVoice**: `POST /api/voice/model/download` (routes.ts:43-89) into `<home>/data/models/zipvoice`; profiles (wav + transcript) under `<home>/data/voices` (engine.ts:19-20).
- **Where**: `~/.openlive/data/models/<id>` (README:385-397); the renderer reaches the agent through the same-origin proxy `apps/web/src/app/api/voice/[...path]/route.ts` which injects `x-openlive-secret`.
- **Regression/bake-off caches** (dev only): `VOICE_REGRESS_CACHE` or OS cache dir `openlive-voice-regress`, files pinned by SHA-256 (tools/voice-regress/src/engines.ts:35-72).

## What `tools/voice-regress` measures

`pnpm voice:regress` (run.ts): 14 corpus replies (corpus.json) streamed as 1-3-word deltas through the real `SentenceChunker`, each chunk through `stripMarkdown` + `toSpeech`, synthesized by the engine as the app runs it (native worker with the catalog's sherpa config, or kokoro-js / Supertonic with the same `trimSilence`), chunks concatenated and compared against a one-go render of the whole reply (`analyze.ts compareReply`). Metrics and absolute gates (summary.ts:13-23): `f0JumpSt` ≤1.5 st, `pauseMs` ≤150, `loudJumpDb` ≤3, `startPitchSt` ≤1.5, `roughJoins` ≤0.1 (share of joins past any threshold), `leadMs` ≤250, `tailMs` ≤600, `durationDev` ≤0.15, `broken` = 0 (NaN/clipping/silent chunks); plus drift against `baseline/<engine>.json` scaled by per-engine `slack`. Tiers: PR = kitten-nano-int8 (3 pooled renders) + kokoro-js; nightly adds kokoro-multi-v1_0 and matcha; local only = supertonic, supertonic-agent, piper-lessac (licenses keep them out of CI). `pnpm voice:bakeoff` (bakeoff.ts) adds per-provider P0 benchmark, first-audio and RTF p50/p95, WER via Parakeet, UTMOS, tag adherence via CED, size and RAM for candidate engines (currently supertonic-agent, kokoro-native, chatterbox-turbo). `pnpm voice:capture` (capture.ts) analyses what the live app actually played from the `ttsCapture.ts` debug recorder (clicks, gaps, DC steps at joins).
